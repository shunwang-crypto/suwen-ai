# 任务

你是一位资深的 AI 教育产品交互与信息架构（IA）设计顾问。下面是一份真实存在、已上线运行的 Web 产品的**完整功能与界面现状文档**（全部来自代码实况，非想象）。请基于它重新设计信息架构与页面结构，目标：界面更清晰、消除冗余跳转、向主流 AI 产品（ChatGPT / Duolingo 等）的交互范式看齐。

---

# 一、产品背景

- **产品名**：苏问 AI 课堂（eduagents），中文界面
- **定位**：资料驱动的个性化 AI 学习产品。学生上传教材/讲义/试卷 → 建知识库 → AI 基于真实资料提供：引用溯源对话、苏格拉底式分级辅导、自适应练习、FSRS 遗忘曲线复习、学习计划、学情成长报告
- **核心理念**（界面处处体现）：「真实学习证据」——阅读和普通对话不改变掌握度，只有真实作答与受控验证才写入画像；每个回答有出处；UNKNOWN≠0（无证据不算 0 分）
- **用户角色**：学生（主体）、教师（组卷导出）、管理员（运营/评估/额度管理）
- **技术栈**：Next.js 16（App Router）+ React 19 + Tailwind CSS 4 + framer-motion；后端 FastAPI；SSE 流式（对话 token 增量、计划/练习生成过程流）；POST + fetch ReadableStream 自解析（带 Authorization）
- **数据模型关键点**：知识库（KB，个人库/机构库，writable 权限）≈ 事实上的「课程」实体；学习计划、练习、辅导均可挂 kb_id；错题复习用 FSRS 调度；首页推荐由 /api/next-actions 计算

- 左侧固定侧栏 **200px**，可折叠为 **64px** 纯图标栏（localStorage `suwen:navigation-collapsed`），折叠时只显示图标、分组标题隐藏、hover 显示 title；移动端为汉堡按钮 + 抽屉（260px，遮罩动画）

- 主内容区 max-width **1480px**，路由切换 fade-in；对话页 overflow-hidden（内部滚动）
- **侧栏现有导航**：一级 4 项——今日 /today、资料 /materials、复习 /reviews、成长 /growth；底部工具区——机构 /orgs、苏问 AI 额度 /billing
- **争议点**：chat、tutor、quiz、plans 四个路由**不在侧栏**（代码 TODAY_TOOL_PATHS，访问时侧栏高亮「今日」），只能通过页内按钮跳转进入；chat 全站唯一显式入口在 onboarding 完成页

- onboarding 属于 BARE 路由（脱离侧栏全屏）——这是目前唯一的「全屏专注」先例

# 三、设计系统（现状）

- **字号**：caption 12px（次要说明，中文最低限）、body-sm 13px（控件正文）、body 14px；页面大标题 20-26px、字距收紧

- **动效**：framer-motion + 150/250/400ms 三档 tokens；自研 8 组 keyframes：edu-fade-up（空态入场）、edu-shake（答错抖动）、edu-pop（徽章弹出）、edu-pulse-hl（高亮脉冲）、edu-breathe（处理中状态点呼吸）、edu-flow-x（拖拽区流光）、edu-draw（对勾描线）、edu-strike（删除线）；**全部带 prefers-reduced-motion 降级**
- **图标**：Figma 导出 mask SVG（14px，currentColor）+ lucide 少量
- **字体栈**：system-ui 优先，中文回落 PingFang SC / 微软雅黑 / Noto Sans SC
- **公共组件库**（components/common + ui）：
  - PageHeader（大标题+副标+action 区）、Card（title/extra 头部）、EmptyState（虚线框 + 8 种自绘几何插画：notebook/calendar/team/chart/target/map/docs/chat）、ErrorBanner（红条，可带重试与关闭）、Skeleton/SkeletonList/SkeletonPage（shimmer 骨架）、Spinner/LoadingState
  - MathText / ModelMarkdown：KaTeX 公式 + GFM 表格/代码；自研 remark 插件——裸 TeX 补 `$` 定界符、`[N]` 引用角标转药丸按钮、`\[..\]`→`$$`、货币 `$5` 转义等流式容错

  - ConfirmDialog（通用确认：Esc/遮罩/焦点圈定/焦点还原/destructive 红钮）、Celebrate（纯 CSS 彩带 20 粒，reduced-motion 降级静态星）、Captcha、PasswordInput（眼睛切换）、CreditsToast
  - useApiResource（GET 三态 hook，request-epoch 防过期响应）、useHydratedLocalStorage（首帧初值+水合恢复+跨页 storage 事件）
