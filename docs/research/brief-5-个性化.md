# Brief-5 · 个性化调研与设计（2026-07-27）

> 输入 = 全仓个性化能力盘点（逐文件实测）+ 外部调研（头部产品/研究前沿/记忆架构/可展示性/教育心理学）。
> 本文是个性化波次的唯一设计出处；实现状态以 git log 为准。

## 1. 盘点结论（实测，非文档转述）

现有"个性化"只有 **KC 掌握度一个维度**，且真正落地仅两处：QA 画像注入（**限绑定知识库路径**，
`chat.py` 有 `if kb_ids:` 门禁）与薄弱点定向出题（kc_names 已自动填充，HANDOFF §6-A4 该条已过期）。

| 断点 | 实况 |
|---|---|
| plan 不读真实掌握度 | `plan_graph.py` diagnose 用 LLM 猜 0.3 保守初值；`existing` 注入分支零调用方 |
| 先修 DAG 拓扑序未接线 | `dag.topological_order` 完备+17 单测，`kc_order` 永远为空（全仓仅存 TODO 之一） |
| tutor 零画像 | 四个 hint prompt 无画像占位；`docs/vlse.md` 画的 BKT→TUTOR 边在代码中不存在 |
| 后端无难度自适应 | difficulty_mix 由前端算（可篡改、hard 恒 0）；**仿真已验证的 ZPD 自适应策略（26.0 题 vs 随机 80.9，p=0.0020）从未接入生产出题**——"论文做完了产品没用"，答辩必被追问 |
| Reflection 只留数字 | insights 的学生原话、tutor misconceptions 全部丢弃，无处存"他在什么语境下困惑" |
| 零用户偏好/零 onboarding | users 表无任何教育属性；注册直接落空 `/chat`；唯一用户控制 = override 0.9 一个按钮 |
| 阈值散落 | 0.4/0.5/0.6/0.8 五处硬编码 → 已建 `eduagents_core/mastery/thresholds.py` 唯一来源 |

## 2. 外部调研要点（来源见文末）

1. **研究共识 = 我们的架构**：LLM 单独估掌握度不可靠（DKT AUC 0.83，LLM 差 ~6%，序列早期最差，
   更新方向性错误，arXiv 2512.23036）→ **hybrid：BKT/FSRS 管状态，LLM 管表达**。TASA（arXiv
   2511.15163，persona+memory+遗忘感知）与我们同构，可作方法学背书。
2. **Duolingo Birdbrain**：预测逐题答对率 → 把学习者锁在 Goldilocks 难度带；个性化核心 KPI =
   "维持最优挑战区"。**BKT 直接支撑此机制**。
3. **Khanmigo**：重心不在算法难度，在**兴趣情境化**（记住学生兴趣，例题嵌入其兴趣世界）+ 苏格拉底教学法。
4. **CMU 2024-25**：可视化解释"为什么推这道题" + 有限学习者控制权（可争辩/可选择）是最打动人的组合；
   OLM（开放学习者模型）= 教育版 XAI。
5. **效应量**（EEF/元分析）：间隔提取练习 g=0.74；元认知/SRL 脚手架 +8 个月/年、ES 0.44-0.69
   （"计划/反思"环节效应最大）；SDT：游戏化对胜任感无效——胜任感须来自**校准难度+进步可见**。
6. **记忆架构**：Mem0 两阶段（extract → ADD/UPDATE/DELETE 决策，非追加）；ChatGPT Memory =
   画像+摘要直接注入 system prompt（非 RAG），用户可见可编辑。

### 红线（伪科学，一票否决级）

- **学习风格匹配（视觉型/听觉型 VARK）**：四项元分析 d≈0.04，已证伪。画像/文案/prompt 中**禁止出现**。
  合法替代 = 按掌握度和求助行为调步长/详略/示例数（scaffolding，不是 styles）。
- 左右脑/多元智能标签化；摄像头情绪识别（隐私+实证弱）；纯 LLM 自由估掌握度；积分排行榜堆砌。

## 3. 设计总纲

**「负责任的混合个性化」：认知状态由可解释的 BKT/FSRS/KC 科学模型掌管，LLM 把它翻译成有温度、
可对话、可争辩的个性化体验；每一个个性化决定都能回答"为什么"。**（同时踩中研究共识、避开伪科学、全部可现场演示）

## 5. 关键决策

| 项 | 决定 |
|---|---|
| 阈值 | `eduagents_core/mastery/thresholds.py` 唯一来源；统一=单一出处不是单一数值 |
| 缓存×个性化 | 保持既有互斥：画像非空 → 禁答案缓存（正确性优先于命中率；空画像新用户不受损） |
| 脱敏 | 画像/偏好出境沿用 P2-7 口径：定性词、不带题干原文、不带 PII |
| 掌握度估计 | 只许 BKT+确定性规则；LLM 不得自由改写掌握度（研究红线，也是我们的叙事卖点） |
| 风格词表 | 讲解风格枚举 = 严谨/口语/类比优先（内容组织维度）；全仓禁止 learning-styles 词汇 |
| 演示叙事 | ① 双画像账号同题对比（规格承诺的演示级证据）② 做错一题→推荐理由实时变化 ③ "我不同意"现场重估 ④ 新会话主动开场 |
