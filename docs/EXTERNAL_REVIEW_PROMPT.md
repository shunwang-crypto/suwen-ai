## 一、项目是什么

**EduAgents**：多智能体个性化学习平台（Web 应用，中文界面）。核心主张是"可验证学习者状态引擎（VLSE）"：问答/辅导/出题/规划/复习五个模块读写同一个学习者状态（BKT 掌握度 + FSRS 遗忘曲线 + 知识点先修图），每次状态变化有审计流水，每个 AI 回答有引用溯源。

**用户可用的完整旅程**：注册登录 → 建知识库（上传 PDF/Word/PPT/MD 或粘贴 URL 导入）→ 带引用溯源的流式问答（Agentic RAG：路由/检索自评/改写重试/联网兜底/明确拒答）→ 苏格拉底辅导（三层提示不直接给答案）→ 出题测评（蓝图确认→生成→判分）→ 错题本（错因五分类）→ FSRS 到期复习 → 学情报告（先修链归因）→ 画像页（可纠正）。另有：机构（企业）共享知识库（邀请码入会、成员只读、个人+机构库联合检索）、教师组卷导出、管理员运营面板（成本归因/延迟分位/故障注入/虚拟时钟）、评估看板（真实评测数据带口径标注）。

## 二、技术栈与架构

- **前端**：Next.js 16 + React 19 + Tailwind 4，21 个页面，SSE 自实现（fetch+ReadableStream），KaTeX 流式渲染，同源代理接后端
- **后端**：FastAPI 全 async + LangGraph 四子图（问答自省环/出题/规划/辅导，PG Checkpointer 支撑 interrupt→resume 跨请求恢复）+ 自研模型网关（DeepSeek/SiliconFlow，live/record/replay/stub 四模式、三档降级链、滑窗熔断、用户日预算强制、故障注入）+ ARQ 异步 worker（文档两阶段摄取、对话洞察 Reflection、学习指南生成）
- **检索**：BGE-M3 稠密 + BM25 稀疏（jieba）+ RRF + bge-reranker 重排 + 两级语义答案缓存（Redis 精确 + Qdrant 语义，数字/否定词复核）
- **数据**：PostgreSQL 18（23 张表，16 张行级安全 RLS FORCE + 非超级用户角色 + 事务级 GUC；机构库三 GUC 只读挂载）· Redis（限流/黑名单/预算/队列/缓存）· Qdrant（向量，租户过滤）· 对象存储（本地 FS，MinIO 实现就绪未启用）
- **安全已有**：JWT + refresh 轮换重放检测、上传三重校验（后缀/魔数/配额）、文档注入过滤（13 条双语模式+红队测试）、SSRF 四道闸（URL 导入）、输入侧内容审核中间件（词表+学术豁免）、限流分桶（登录 5/分、续期 60/分、API 120/分）
- **质量基线**：259 单元测试 + 38 集成测试全绿（集成测试历史上抓过 5 个真 bug 并回归钉死）；lint 零告警；docker-compose 部署编排已写（本机因网络未验，开发用本地进程栈）

## 四、已知差距（我们自曝的，请勿浪费篇幅重复发现，可指出低估之处）

1. 无任何备份/恢复策略；单机单盘
2. 密钥明文在 .env，JWT secret 为开发值，无轮换
3. 无 HTTPS/域名/ICP 与算法备案/隐私政策/用户协议/未成年人模式文档
4. 无密码找回、无邮箱验证、无注册验证码/风控——公网开放即被脚本注册灌爆
5. 无监控告警（Langfuse/Prometheus 未接）、无 CI/CD、无日志留存策略
6. PG/Redis/Qdrant 全部单点，无高可用
7. LLM 供应商实质单点（DeepSeek 主力，降级链只有一家备胎）
8. 输出侧内容审核未接入流式链路（仅输入侧拦截）
9. SSRF 存在 DNS rebinding 残余风险（已记档未修）
10. 移动端仅"不破版"，无通知/分享/多设备会话管理/计费
11. 压测仅缩水规模初测（stub 档 30 并发），未做完整口径
12. 真人有效性验证缺失（闭环有效性目前是合成学生仿真证据）

## 五、请你重点挖掘的方向（已知之外）

按真实用户第一周使用路径逐步推演，重点想以下场景我们扛不扛得住：

- **账号与滥用**：撞库/薅羊毛（LLM 成本攻击是真金白银）、越权路径、会话固定、CSRF（refresh cookie SameSite 语义）、邀请码爆破
- **数据生命周期**：用户注销与数据删除权（个保法）、数据导出、软删除 vs 物理删除、向量库与对象存储的删除一致性、孤儿数据
- **异常路径产品体验**：LLM 超时/配额打满时用户看到什么、上传 50MB 卡住怎么办、SSE 断线重连语义、并发编辑冲突
- **运营必需品**：客服/反馈通道、封号能力、公告系统、灰度发布、数据看板之外的增长埋点
- **成本模型**：单用户单日 LLM 成本上限设计是否成立、缓存命中率对成本曲线的真实影响、免费额度策略缺失
- **教育域特有**：内容准确性责任边界（AI 答错了误导考生怎么办）、题目版权、学情数据的敏感性等级
- **工程暗债**：会话消息与 LangGraph 检查点双轨存储的膨胀（检查点已 7.7 万行 vs 消息 3 千行）、Redis 键无统一 TTL 治理、时区处理、i18n 硬编码
