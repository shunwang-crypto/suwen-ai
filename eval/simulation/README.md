# M5 合成学生闭环有效性实验 — 设计说明书

回答评委必问的一个问题: **“你怎么证明自适应出题比随机出题好?”**
用 300 名/臂 的合成学生 (30 学生 × 10 seeds), 在受控环境里定量测出
自适应策略毕业所需题量显著少于两条基线, 并给出 p 值、效应量与敏感性分析。

## 1. 双模型架构 (异构, 参数不共享)

| 侧 | 模型 | 结构 | 参数 | 谁能看到 |
|---|---|---|---|---|
| 环境侧 (作答) | IRT 3PL | 连续潜能力 θ + 题目难度 b + 题型异质猜测 c | θ~U(0.1,0.9); b∈{-1,0,+1}; c∈{0.25,0.5,0.06,0.05} | 只有仿真环境自己 |
| 产品侧 (估计) | BKT | 二元潜变量 HMM (会/不会) | P(L0)=0.3, P(T)=0.15, P(G)=0.2, P(S)=0.1 | 选题策略只能看 BKT 的 P(L) |

作答模型:

```
P(答对) = c + (1-c) · sigmoid(1.7 · (z - b)),   z = logit(θ) = ln(θ/(1-θ))
```

先取 logit 再进 sigmoid 是量纲修正: θ 与 BKT 的 P(L) 同在 [0,1] 上, MAE(P(L), θ)
两边直接可比; 且 z 值域约 ±2.2 恰好落在标准 IRT 能力尺度上。若把 θ∈(0.1,0.9)
直接代入 sigmoid(1.7(θ-b)), 最差学生做 easy 题的正确率仍高达 0.87, 区分度失效。

估计器直接复用产品线上的 `eduagents_core.mastery.bkt.bkt_update` (一行未改),
因此实验结论对线上代码**直接成立**, 且本套件可作为改动 BKT 实现前后的回归资产。

## 2. 为什么这不是循环论证 (正式论证)

**质疑**: “你用自己造的学生验证自己的算法, 学生模型要是照着估计器造的, 结论是套套逻辑。”

**回应分四层**:

1. **结构异构**。作答模型是 IRT——连续潜变量 + 题目参数 (难度、题型异质猜测下界);
   估计模型是 BKT——二元潜变量隐马尔可夫链。两者的状态空间 (连续 vs 二元)、
   观测方程 (logistic vs slip/guess 混淆矩阵)、动力学 (确定性增长 vs 概率转移)
   全部不同。BKT 想“赢”, 必须跨过一个它在结构上无法表达的生成过程。
2. **参数零共享**。作答侧的 θ、b、c 与估计侧的 P(L0)/P(T)/P(G)/P(S) 没有任何一个
   数字互相传递; 尤其估计器只有单一全局 guess=0.2, 并不知道题型真实猜对率
   (0.05~0.5 变化范围 10 倍)——估计器是在“错误设定 (misspecified)”条件下工作的,
   这恰恰是对真实场景的更严苛模拟。
3. **学界同范式**。用 IRT 族模型模拟作答、用 BKT 做掌握度追踪的异构双模型架构
   是知识追踪领域的标准做法 (arXiv 2605.21613 用 AFM——IRT 族——模拟学生、BKT 追踪);
   Baker 等人的 BKT 参数恢复研究同样采用“真值参数生成数据 → 拟合 → 比误差”范式。
   理论上 BKT 稳态分布可导出 IRT 型 logistic 曲线 (slip/guess 对应 4PL 上下渐近线),
   两者同源而参数化独立——因此用 IRT 环境考察 BKT 既公平又不自证。
4. **敏感性兜底**。即便有人坚持“参数可能被凑过”, 我们把 BKT 估计器参数
   P(T)/P(G)/P(S) 各扰动 ±50%、毕业阈值三档 (0.8/0.9/0.95, 0.95 为
   Corbett & Anderson 文献标准)、学习率 λ 三档 (0.08/0.15/0.25) 全部重跑,
   结论方向均不变 (见 report.md 敏感性表)。结论若是凑出来的, 不可能在
   10 个变体下全部存活。

**定位诚实声明**: 本实验验证的是**算法层** (估计器正确性 + 选题策略相对优劣),
不宣称替代真人实验; 真人小规模试用在路线图中。

## 3. 两个子实验 (拆分原因: 静态 θ 与“毕业题量”指标内在冲突)

若 θ 静态, “毕业题量”只反映估计器收敛速度; 若 θ 动态, MAE 收敛曲线又混入学习效应。
所以拆成两问各答一问:

### 实验 A — 估计准确性 (θ 静态): “掌握度数字准不准”

- N=30 学生 × K=8 KC (带先修 DAG), θ~U(0.1,0.9) 固定; 每学生 T=40 题。
- 指标: 每轮全体 MAE(P(L), θ); 收敛判定 = 滑窗 5 轮极差 <0.01 且距终值 <0.02。
- 图: fig1 收敛曲线 (三臂 + 95% CI 带), fig3 校准散点 (终局 P(L) vs θ, 对角线 + R²)。
- **解读预警 (如实报告)**: BKT 的 P(T)>0 内置“练习即可能学会”假设, 静态环境故意
  违反它, 因此 P(L) 绝对刻度会随轮数上偏 (MAE 先降后升、R² 为负)。这是估计器在
  错误设定下的真实行为暴露, 不做美化; 详见 report.md 的实验 A 分析段。

### 实验 B — 教学效率 (θ 动态): “自适应教学省多少题” (主实验)

- 学习模型 (对三臂完全一致且隐藏于环境): 每练一次 θ ← θ + rate·(0.95 − θ);
  rate = λ=0.15 (答对) / λ/2 (答错, doer effect); 前置 KC θ<0.5 时后继增长再减半。
- 毕业 = 所有 KC 的 BKT P(L) > 0.8; 单学生上限 200 题 (未毕业按 200 保守删失)。
- **预注册唯一主指标: 毕业所需题量**; 次要: 200 题内毕业率、终局真实 θ 均值
  (防“只刷估计不刷学习”)。
- 图: fig2 毕业生存曲线, fig4 三臂题量箱线图。

## 4. 三条策略臂

| 臂 | 逻辑 | 角色 |
|---|---|---|
| adaptive | **唯一 BKT 驱动的臂**: 跳过已达标 KC; 优先 0.3<P(L)<0.8 的弱项 (最近发展区); 难度匹配 P(L) (<0.5→easy, <阈值→mid, ≥阈值→hard) | 产品策略 |
| random | 全 KC 均匀随机 + 难度均匀随机, 零状态 (估计盲) | 随机基线 |
| ladder | KC 轮转 (练得最少者优先) + 固定 easy→mid→hard 阶梯 (每档 5 题), 不看估计 (估计盲) | 非自适应启发式, 回应“你只是赢了随机” |

三条设计纪律 (答辩要点):

1. **基线估计盲**: random/ladder 不读任何 BKT 状态 (含“该 KC 是否已达标”)。
   若基线也按达标过滤, 等于把 BKT 信号泄漏给对照组, 差距将无法归因于
   “BKT 驱动”本身。毕业停练是环境级规则 (全 KC P(L)>阈值 即停), 三臂一致。
2. **难度档位锚定掌握阈值**: hard 档只派给估计已达标的 KC (≥阈值)——未达标不派
   最难档是产品辅导子图“提示阶梯/脚手架”的同一原则; 0.5/阈值 两个切分点分别锚定
   “更可能会了”与产品毕业语义, 不是自由调出来的数字, 且随阈值敏感性 (0.9/0.95)
   自动缩放。
3. **题型对三臂同分布随机抽取**, 不作为策略变量——否则自适应可以靠专挑低猜对率
   题型提高信息量, 胜利将无法干净归因于教学逻辑。

## 5. 统计设计

- 10 seeds; 同 seed 三臂共享同一批学生 θ **和同一条作答随机流** (共同随机数,
  配对设计, 方差大幅缩减)。
- 对 10 个 seed 级均值做双尾 **Wilcoxon 符号秩检验** (n=10, 无并列时走精确分布,
  不假设正态), 报告 p + 配对 **Cohen's d** + t 分布 95% CI。
- 统计函数零 scipy 依赖 (`stats.py` 纯手写, 单测含手算校验)。

## 6. 可复现性

- 全程 `numpy.random.Generator` 显式种子 (`default_rng([seed, student, stream])`),
  禁全局 `random`/`np.random` 单例; 同 seed 逐位复现 (单测断言)。
- 纯数值仿真, 零 LLM 调用, 全量 (A+B+10 变体敏感性) 单机分钟级。
