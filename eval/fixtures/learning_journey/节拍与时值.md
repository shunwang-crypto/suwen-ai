# 节拍与时值

## 拍号

拍号写作上下排列的两个数字。对简单拍子，上面的数字表示每小节有几拍，下面的数字表示用几分音符作一拍。以四分音符为一拍时，3/4 的一小节有三拍，4/4 的一小节有四拍。拍号本身没有指定演奏的快慢，速度还需另行给定。

读一小节前，先写下所用的拍单位，再在每个拍点上画记号，最后比较音符和休止符占用的总时值与小节容量是否一致。区分 3/4 与 2/4 时，把总拍数和拍单位分别标出。不能只因一小节写了三个符号就判定它有三拍，因为不同符号的时值可能不同。本节例子只讨论简单拍子。

## 附点音符

单附点音符的附点把原音符的时值延长一半。它延长的是原来时值的一半，不是固定增加一拍。在四分音符为一拍的简单拍子中，一个四分音符占一拍，它的单附点增加半拍，总时值为一拍半。一个二分音符占两拍，它的单附点则增加一拍，总时值为三拍。

可以把单附点音符改写为原音符与时值减半的同音高音符用延音线相连。这样可以逐项核对时长。例如单附点四分音符等时于一个四分音符与一个八分音符相连，两者合在一起只起音一次。比较附点对两种不同时值音符的影响时，先分别找原值，再各自取一半，最后相加。
