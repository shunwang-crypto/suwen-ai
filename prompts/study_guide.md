## 输出要求

只输出一个 JSON 对象，不要任何解释性文字或代码块围栏。结构如下：

```
{
  "outline": [
    {
      "title": "模块标题（8-20 字，概括一个学习单元，不要照抄章节号）",
      "summary": "该模块讲什么、为什么重要（40-80 字，面向初学者）",
      "kc_names": ["该模块涉及的知识点名称，从上面词表中选，最多 4 个"]
    }
  ],
  "glossary": [
    {"term": "术语", "definition": "一句话定义（20-50 字，不用公式也能读懂）"}
  ],
  "suggested_questions": ["入门提问，3 到 5 条"]
}
```

约束：
- `outline` 3-6 项，按学习顺序（先修在前）排列，覆盖资料主干，不要逐章罗列。
- `kc_names` 只能取自上面的知识点词表；词表为空时给空数组。
- `glossary` 4-8 条，挑初学者最容易卡住的术语。
- `suggested_questions` 必须是能用这个知识库的内容回答的具体问题（不是"这本书讲了什么"这类空问题），每条 10-30 字，直接以问句形式给出。
- 全部使用中文；数学表达式用 LaTeX 行内写法 `$...$`，不得省略闭合 `$`，不得把中文正文放进公式定界符，也不得裸输出 `\\frac`、`\\lim` 等完整公式。
